# Evidências e Histórico

Esta área reúne o que permite reconstruir o projeto sem depender do histórico do chat: linha do tempo, inventário da `main`, matriz de entregas, estados de publicação e fontes externas.

## Classificação usada

- **Confirmado no repositório:** existe no código, documentação ou commit identificado.
- **Validado localmente:** passou por teste, build, lint, smoke test ou verificação equivalente no ambiente local.
- **Publicado:** commit enviado para `origin/main` ou deployment informado como concluído.
- **Verificado publicamente:** comportamento observado por HTTP, navegador ou painel externo em data registrada.
- **Pendente:** requisito conhecido que ainda não possui evidência de conclusão.
- **Não confirmado:** hipótese, causa ou informação que não recebeu evidência suficiente.

## Regra de uso

Toda nova entrega deve registrar data, objetivo, arquivos ou serviço afetado, evidência disponível, limitações e próximo passo. Senhas, tokens, chaves privadas e dados pessoais de clientes não entram nesta área.
