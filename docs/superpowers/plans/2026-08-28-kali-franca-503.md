### Task 2: Anchor the production server and verify the incident path

**Files:**
- Modify: `apps/kali-franca-membros/server.mjs`
- Test: `apps/kali-franca-membros/tests/server-runtime.test.mjs`

**Interfaces:**
- Consumes: `import.meta.url` and the existing `PORT` value.
- Produces: `next({ dev: false, hostname, port, dir: appDirectory })`, with the app directory resolved through `fileURLToPath(new URL('.', import.meta.url))`.

- [x] **Step 1: Implement the minimal fix**

```js
import { createServer } from 'node:http';
import { fileURLToPath } from 'node:url';
import next from 'next';

const port = Number.parseInt(process.env.PORT ?? '3000', 10);
const hostname = '0.0.0.0';
const appDirectory = fileURLToPath(new URL('.', import.meta.url));
const app = next({ dev: false, hostname, port, dir: appDirectory });
const handle = app.getRequestHandler();

await app.prepare();

createServer((request, response) => {
  handle(request, response);
}).listen(port, hostname, () => {
  console.log(`Kali França Membros disponível em http://${hostname}:${port}`);
});
```
