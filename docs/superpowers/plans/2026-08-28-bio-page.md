# Página Bio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and publish a static Kalì Franca link-in-bio page at `/bio/` with three deterministic destinations and no fabricated URL for Reprogramação Energética.

**Architecture:** Add an isolated `bio/index.html` route and `bio/styles.css` stylesheet. The page imports `brandbook/tokens.css`, uses only HTML/CSS, and keeps external destinations as explicit links while rendering the unavailable destination as a non-link state.

**Tech Stack:** Semantic HTML5, CSS custom properties, shared Kalì token CSS, Node.js built-in test runner, Git/Hostinger static publication.

## Global Constraints

- Preserve the existing dirty, untracked project directories `cofre-kali/`, `design-system/`, and `referencias/`.
- Use `brandbook/tokens.css` as the visual source of truth; do not duplicate raw brand colors in the page stylesheet.
- Keep copy honest: no metrics, prices, testimonials, guarantees, or unvalidated results.
- Use the exact supplied destination URLs and leave Reprogramação Energética without a URL.
- Maintain Portuguese Brazilian markup (`lang="pt-BR"`) and accessible focus/reduced-motion behavior.
- Run the full relevant verification before claiming completion or pushing.

**Interfaces:**

- [ ] **Step 1: Write the minimal semantic page**

Implement `bio/index.html` with:

```html
<a class="skip-link" href="#conteudo">Pular para o conteúdo</a>
<main id="conteudo">
  <section class="bio-card" aria-labelledby="bio-title">
    <header class="bio-header">
      <img src="../profile.jpg" alt="Kalì Franca" width="150" height="150">
      <p class="bio-kicker">Kalì Franca</p>
      <h1 id="bio-title">Presença, clareza e <em>expansão.</em></h1>
    </header>
    <nav class="bio-destinations" aria-label="Destinos da Kalì Franca">
      <!-- Mentoria: external anchor with exact WhatsApp URL -->
      <!-- Reprogramação: non-anchor pending card with Em breve -->
      <!-- YouTube: external anchor with exact channel URL -->
    </nav>
  </section>
</main>
```

Each destination must include an inline decorative icon with a text alternative through the card label, an explicit status/CTA, and a minimum 44px interactive surface where applicable. External anchors use `target="_blank"` and `rel="noopener noreferrer"`.

- [ ] **Step 2: Write the token-based visual system**

Implement `bio/styles.css` using `../brandbook/tokens.css` values only for brand colors, spacing, fonts, borders, surfaces, and component treatments. Include:

- full viewport atmospheric background with radial gradients and orbit lines;
- centered card with responsive max width, translucent surface, warm border and soft shadow;
- circular profile image with Alabastro/Ouro treatment;
- destination cards with hover/focus/active states, a distinct primary Mentoria card, and an explicit non-clickable `Em breve` state;
- mobile layout that becomes edge-to-edge with adequate padding;
- `:focus-visible`, `@media (max-width: ...)`, and `@media (prefers-reduced-motion: reduce)`.
