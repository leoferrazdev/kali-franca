# Eleva 5D LP V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar e publicar uma terceira landing page do Eleva 5D em `/lp-5d/v3/`, com canvas editorial contínuo e sem seções claras dominantes.

**Architecture:** A V3 estática e independente será composta por `index.html`, `styles.css` e `app.js` dentro de `lp-5d/v3/`. Ela reutilizará os tokens e assets existentes, manterá a raiz e `/eleva-5d-b/` intactas e receberá contratos estáticos próprios.

**Tech Stack:** HTML semântico, CSS responsivo, JavaScript vanilla para tracking, Node.js `node:test`, servidor estático local e Git/GitHub `main`.

## Global Constraints

- Rota pública: `https://kalifranca.com.br/lp-5d/v3/`.
- Identidade oficial: **Kalì Franca**.
- Canvas contínuo em umbra/vinho; não usar cards ou seções claras dominantes.
- Reutilizar `brandbook/tokens.css`, fotos aprovadas e favicon existente.
- Oferta exibida como `R$497` e `acesso anual ao Método, pelo seu aplicativo personalizado`.
- Manter `data-cta="hero"`, `data-cta="offer"`, `data-cta="final"` e os eventos `eleva5d_cta_click` e `eleva5d_scroll_depth`.
- Não simular checkout, pagamento, compra ou entitlement.
- Alvos interativos mínimos de 44px, foco visível, `prefers-reduced-motion` e sem overflow horizontal.

```js
import assert from 'node:assert/strict';
import { existsSync, readFileSync } from 'node:fs';
import test from 'node:test';
import { resolve } from 'node:path';

const root = resolve(import.meta.dirname, '..');
const read = (file) => readFileSync(resolve(root, file), 'utf8');

test('a V3 existe na rota independente e usa o contrato editorial', () => {
  const html = read('lp-5d/v3/index.html');
  assert.ok(existsSync(resolve(root, 'lp-5d/v3/index.html')));
  assert.match(html, /<html[^>]+lang=["']pt-BR["']/i);
  assert.match(html, /<main[^>]+id=["']conteudo["']/i);
  assert.equal((html.match(/<h1\b/gi) || []).length, 1);
  assert.match(html, /Eleva 5D/i);
  assert.match(html, /Kalì Franca/i);
  assert.match(html, /R\$497/i);
  assert.match(html, /acesso anual ao Método/i);
  assert.doesNotMatch(html, /variação B|ELEVA 5D \/ B/i);
});

test('a V3 contém narrativa, cinco movimentos, FAQ e CTAs rastreáveis', () => {
  const html = read('lp-5d/v3/index.html');
  for (const movement of ['Reprogramar', 'Alinhar', 'Manifestar', 'Sustentar', 'Elevar']) {
    assert.match(html, new RegExp(movement, 'i'));
  }
  for (const cta of ['hero', 'offer', 'final']) {
    assert.match(html, new RegExp(`data-cta=["']${cta}["']`, 'i'));
  }
  assert.match(html, /perguntas frequentes|antes de você entrar/i);
  assert.match(html, /<details>/i);
});

test('a V3 usa paths de produção e acessibilidade básica', () => {
  const html = read('lp-5d/v3/index.html');
  const styles = read('lp-5d/v3/styles.css');
  const script = read('lp-5d/v3/app.js');
  assert.match(html, /brandbook\/tokens\.css/i);
  assert.match(html, /assets\/kali-og-social-authority\.png/i);
  assert.match(html, /Pular para o conteúdo/i);
  assert.match(styles, /:focus-visible/);
  assert.match(styles, /min-height:\s*44px/);
  assert.match(styles, /prefers-reduced-motion/);
  assert.match(styles, /@media\s*\([^)]*max-width/i);
  assert.match(script, /eleva5d_cta_click/i);
  assert.match(script, /eleva5d_scroll_depth/i);
});

test('a V3 usa canvas contínuo e contraste claro no fundo escuro', () => {
  const styles = read('lp-5d/v3/styles.css');
  assert.match(styles, /--v3-ink|--b-ink/i);
  assert.match(styles, /background:\s*var\(--v3-ink\)/i);
  assert.match(styles, /color:\s*var\(--v3-paper\)/i);
  assert.match(styles, /\.v3-flow|\.continuous-canvas/i);
  assert.doesNotMatch(styles, /background:\s*#fff|background:\s*white/i);
});

test('a V3 mantém as outras rotas de vendas independentes', () => {
  assert.ok(existsSync(resolve(root, 'index.html')));
  assert.ok(existsSync(resolve(root, 'eleva-5d-b/index.html')));
});
```

### Task 2: Criar a rota e o shell editorial contínuo

**Files:**
- Create: `lp-5d/v3/index.html`
- Create: `lp-5d/v3/styles.css`
- Create: `lp-5d/v3/app.js`

**Interfaces:**
- Consumes: `brandbook/tokens.css`, `assets/kali-og-social-authority.png`, `assets/kali-expansao-editorial-vertical-01.png` e `fotos/geradas-ia/kali-hero-autoridade-horizontal-02.png`.
- Produces: documento semântico, canvas visual escuro contínuo e tracking dos CTAs/scroll.

- [ ] **Step 1: Criar o HTML da V3**

O `<head>` deve usar canonical `https://kalifranca.com.br/lp-5d/v3/`, `og:image` pública, favicon `/favicon.svg`, `brandbook/tokens.css` e `styles.css?v=v3-1`. O corpo deve conter `skip-link`, header mínimo, um `main#conteudo` e uma sequência de blocos narrativos sem classes de cards claros.

Usar a seguinte ordem de elementos: hero, reconhecimento, transição 3D/4D/5D, método, rotina, cinco espaços, Eu Soul, Corte Energético, especialista, oferta anual, FAQ e CTA final. Os CTAs devem apontar para `#oferta` enquanto não existir checkout.

- [ ] **Step 2: Criar o CSS com um único campo cromático**

Definir `--v3-ink: #0e0b0a`, `--v3-wine: #32121f`, `--v3-plum: #7a2b44`, `--v3-paper: #f4ede4`, `--v3-gold: #c9a66b` e `--v3-line: rgba(244,237,228,.2)`. O fundo deve permanecer escuro no `body` e nas regiões narrativas. Separar momentos com `padding-block`, linhas parciais, pseudo-elementos, índices e gradientes sutis; não usar superfícies claras dominantes, cards brancos ou sombras de cartão.

Implementar os breakpoints `900px` e `600px`, largura fluida do canvas, imagens com `object-fit: cover`, foco visível, alvo mínimo de 44px e `prefers-reduced-motion`.

- [ ] **Step 3: Criar o JavaScript de tracking**

Registrar `eleva5d_cta_click` no clique dos elementos `[data-cta]` com `{ cta, href, path: location.pathname }`. Registrar `eleva5d_scroll_depth` uma vez por limiar em `25`, `50`, `75` e `100`, usando `IntersectionObserver` para o marcador final e fallback de `scroll` com `requestAnimationFrame`.
